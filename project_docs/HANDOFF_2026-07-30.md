## 6. Gotchas (learned the hard way)

- **PowerShell 5.1 mangles embedded double-quotes in `git commit -m` here-strings** — write

- **One stats-API crawler at a time** (stats.nba.com); odds/news/official.nba.com hosts are
  independent. LeagueGameLog is fine; per-game V2 endpoints are dead (V3 only).

  handles); misc has a DiLeo/Gustafson ghost-row dupe across 230 files (masters dedupe by
  finite-minutes rule).

  chaos — always go through `wnba_schema` / `data/masters/`.
- **Charter flights from 2024** may invalidate B2B fatigue features learned on 2021-23.
- Agents: never git, never register/render; give explicit file boundaries to avoid collisions;
  they deliver evidence, orchestrator verifies.
- **Dimensional-check every adjustment formula BEFORE registering it** (RAPM is per-100-poss:
  minutes-weighted-mean lineup value × 4.0 = game points; the v1 bracket registered 200×mean
  ×0.8 ≈ 40× too big — caught in smoke, cost a dead registration). Smoke-run BEFORE the real
  run, always; smoke uses a scratch registry so a broken formula never pollutes the ledger.
- MAE on zero-inflated mixtures grades MEDIANS (hard 0/full predictions win it); the
  aggregation layer consumes MEANS — pick the registered metric to match the consumer.
