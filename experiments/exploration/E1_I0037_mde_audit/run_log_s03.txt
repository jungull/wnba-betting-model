A. THE SIGN-FLIP FLOOR: below how many blocks can a two-sided sign-flip null NEVER reject?
==================================================================================================
  A two-sided block sign-flip over nb blocks has 2^nb equally likely sign patterns.  The
  observed pattern is one of them, and the all-flipped pattern gives |draws| = |real|
  exactly.  So at least 2 of 2^nb patterns are >= |real|, and
        p_min = 2 / 2^nb = 2^(1-nb)
  p_min < 0.05 requires nb >= 6.  BELOW SIX BLOCKS THE TEST CANNOT PRODUCE p < 0.05 AT
  ALL, so its MDE is +infinity regardless of effect size, sample size or null sd.

    nb=3    p_min = 2^(1-nb) = 0.25000   type-I(R=2000) = 0.0000   can ever reject: NO
    nb=4    p_min = 2^(1-nb) = 0.12500   type-I(R=2000) = 0.0000   can ever reject: NO
