5. COMPONENT-WISE INJECTION -- IS THE MATCHED NULL POWERED AGAINST EVERY COMPONENT?
====================================================================================================
  PREREG 7: a composite candidate needs a null valid for EVERY component, verified by
  component-wise injection. The candidate is split into its BETWEEN-entity and
  WITHIN-entity parts; a signal of known size is planted in EACH separately and the
  matched null's rejection rate is measured. An arm is valid only if it has power against
  every component carrying >= 10%% of the candidate's variance.
  DESIGN. A signal is planted into a SYNTHETIC response so it cannot cancel or reinforce the
  cell's own existing effect: y_rep = yhat_base + sd(e)*z_rep + b*c_perp, fresh z_rep per
  replicate, b = sqrt(delta*SST/(c_perp.c_perp)) so the planted increment is exactly delta.
  Power = rejection rate of the MATCHED null over 200 replicates; type-I is the delta = 0 row.
  The permutation bank is drawn ONCE per cell and reused across replicates, which is a valid
  fixed-permutation null and makes the residualised bank reusable (x_perp does not depend on y).
  Run on the three cells with the largest ARM 3 statistic plus the pure-noise control.
